# 🏎️ טורבו קארט — Turbo Kart
> **סלוגן:** מרוצים בקצב אחר.

משחק מרוצים תלת־ממדי מקצועי, צבעוני ומהנה לאנדרואיד בסגנון Cartoon 3D (בהשראת Beach Buggy Racing 2), עם פיזיקת קארט ארקיידית, 20 מכוניות שונות, 36 מסלולים ב-12 עולמות, 10 כוחות מיוחדים, יריבי AI חכמים, עורך מסלולים מובנה, וממשק מלא בעברית.

---

## 🌟 תכונות מרכזיות

1. **מערכת נהיגה ופיזיקה ארקיידית:**
   - האצה, בלימה, נסיעה לאחור והיגוי חד.
   - **מערכת החלקה מבוקרת (Drift):** צבירת ניצוצות בפניות והאצת מיני-טורבו ביציאה.
   - **מערכת פעלולים (Stunts):** סיבובים וגלגולים באוויר בעת זינוק מרמפות, נחיתה מושלמת מעניקה בונוס טורבו והודעות עידוד בעברית.
   - משטחים משתנים: אספלט מהיר, חול/דשא מאט, קרח חלקלק ומשטחי האצה זוהרים (Boost Pads).

2. **מוסך 20 המכוניות:**
   - 20 קארטים ייחודיים: *באגי חוף, טורבו ספורט, ג'יפ שטח, מפלצת הגלגלים, פורמולה, מכונית מדבר, שלג, עתידנית, משטרה, רכב כיבוי, זהב, קלאסית, אדומה, משוריינת, סופר-טורבו, חלל, ג'ונגל, כחולה, אליפות, טורבו אגדית*.
   - צפייה תלת-ממדית אינטראקטיבית במוסך עם אפשרות סיבוב 360°.
   - שדרוג 4 מאפיינים: מנוע, שליטה, טורבו ושלדה (עד 5 כוכבים).
   - התאמה אישית של צבעי מרכב.

3. **36 מסלולים ב-12 עולמות:**
   - *חוף הטורבו, מדבר הסערות, פסגת הקרח, הר הגעש, ג'ונגל פראי, עיר האורות, טירת המרוצים, מסלול החלל, אי האוצרות, יער הסערות, אצטדיון האלופים, כביש העננים*.
   - 3 וריאציות מסלול לכל עולם: קלאסי (קל), קפיצות (בינוני), גרנד פרי אקסטרים (קשה).
   - תנאי מזג אוויר ותאורה דינמיים: שמשי, שקיעה, גשם, סערה ולילה.

4. **10 כוחות מיוחדים (קופסאות הפתעה):**
   - 🚀 **טורבו:** האצת נייטרו מתפרצת.
   - 🛡️ **מגן:** בועת הגנה מפני פגיעות.
   - ❄️ **קרח:** השלכת מלכודת קרח המסחררת מתחרים.
   - 🌪️ **טורנדו:** מערבולת רוח הפוגעת במובילי המרוץ.
   - ⚡ **ברק:** מכת חשמל המאטה את כל המתחרים.
   - 🧲 **מגנט:** שאיבת מטבעות אוטומטית.
   - 👻 **רוח רפאים:** מעבר דרך מכשולים ומכוניות.
   - 🎯 **טיל צבע:** טיל מונחה המכתים ומאט יריב.
   - 🦘 **קפיצת ענק:** זינוק מעל מכשולים ומתחרים.
   - 🔥 **טורבו כפול:** הפעלת שני מבערי נייטרו עוצמתיים.

5. **6 מצבי משחק:**
   - **אליפות הטורבו:** גביעי טורניר (4 מרוצים רצופים, צבירת ניקוד ופרסי גביעים מוזהבים).
   - **מרוץ נגד השעון:** שבירת שיאי הקפה אישיים.
   - **מרוץ חופשי:** התאמה אישית של מסלול, רכב ויריבים.
   - **מרוץ הכוחות:** שפע קופסאות הפתעה וקצב אקשן מוגבר.
   - **טורניר האלופים:** יריבי AI ברמת קושי מקסימלית.
   - **נהיגה חופשית:** אימון פעלולים ומסלולים ללא מגבלת זמן.

6. **עורך מסלולים מובנה:**
   - בניית מסלולים מקוריים באמצעות קטעי דרך, פניות, רמפות, קופסאות הפתעה ומחסומים.
   - תצוגת מפה דו-ממדית ונסיעת מבחן מיידית בתלת-ממד!

7. **שליטה מותאמת לאנדרואיד:**
   - כפתורי מגע נוחים (היגוי, גז, ברקס, החלקה, אפשרות לגז אוטומטי).
   - הגה וירטואלי רגיש ומדויק.
   - שליטה בהטיית המכשיר (חיישן תאוצה / אקסלרומטר) עם מד רגישות.

8. **מנוע סאונד ומוזיקה פרוצדורלי:**
   - מנוע מרוצים נוהם העולה בטורים בהתאם למהירות.
   - חריקת צמיגים בהחלקה, צליל טורבו, אפקטי התנגשות וצלצול מטבעות.

## 🛠️ מבנה הפרויקט

```
├── app/                      # פרויקט Android Studio מקומי (Kotlin + Jetpack Compose)
│   ├── src/main/java/com/example/
│   │   ├── engine/           # מנוע תלת-ממד, פיזיקת קארט, AI ומנוע סאונד
│   │   ├── model/            # 20 מכוניות, 36 מסלולים, כוחות ומצבי משחק
│   │   ├── ui/screens/       # מסכי משחק, מוסך, עורך מסלולים, הגדרות
│   │   └── data/             # שמירת התקדמות מקומית (מטבעות, שדרוגים ושיאים)
│   └── res/                  # גופנים (Rubik עברית), צבעים, אייקונים
├── godot_project/            # פרויקט מנוע Godot 4 מלא
│   ├── project.godot         # הגדרות מנוע Godot 4.3 (Compatibility renderer)
│   ├── export_presets.cfg    # הגדרות ייצוא ל-Android APK
│   ├── scripts/              # סקריפטים ב-GDScript (פיזיקה, AI, מנהלי מרוץ ושמירה)
│   └── scenes/               # סצנות המשחק (תפריט, מרוץ, רכב)
└── .github/workflows/
    └── build-android.yml     # תהליך CI/CD לבניית TurboKart.apk והפצת Release
```

## 🚀 בניית APK אוטומטית באמצעות GitHub Actions

הקובץ `.github/workflows/build-android.yml` מאפשר לקמפל את המשחק ישירות ל-APK:

### 1. הפעלה ידנית (Manual Trigger):
- היכנסו ללשונית **Actions** במאגר ה-GitHub.
- בחרו ב-**Build Turbo Kart Android APK**.
- לחצו על **Run workflow**.

### 2. הפעלה אוטומטית על פי תגית גרסה (Release Tag):
דחיפת תגית גרסה מפעילה את הבנייה ומפרסמת מהדורת GitHub Release עם קובץ ההתקנה:
```bash
git tag v1.0.0
git push origin v1.0.0
```

### 3. חתימת Release קבועה (אופציונלי):
כדי לחתום בחתימת Release קבועה שתאפשר התקנת עדכונים על אותה אפליקציה, הגדירו בהגדרות המאגר (`Settings -> Secrets and variables -> Actions`):
- `ANDROID_KEYSTORE_BASE64` — תוכן קובץ ה-Keystore מקודד ב-Base64.
- `ANDROID_KEYSTORE_PASSWORD` — סיסמת ה-Keystore.
- `ANDROID_KEY_ALIAS` — שם ה-Alias של מפתח החתימה.
- `ANDROID_KEY_PASSWORD` — סיסמת ה-Alias.

*הערה:* אם הסודות אינם מוגדרים, ה-Workflow יוצר אוטומטית מפתח Debug תקין ומפיק `TurboKart.apk` הניתן להתקנה מיידית בכל מכשיר אנדרואיד!
